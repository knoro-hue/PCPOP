# PC POP メーカー（ドスパラ商品ページ → A4 POP）

ドスパラの BTO PC 商品ページの URL を入れると、スペック・画像・価格を取得して A4 縦の店頭 POP を作るローカルツールです。

## 必要なもの
- Python 3.9 以上（追加ライブラリ不要）

## 起動
```
python pcpop.py
```
Windows ならエクスプローラーで `start.bat` をダブルクリックでも OK。
ブラウザで http://127.0.0.1:8765/ が開きます。

## 使い方
1. 商品 URL（例: `https://www.dospara.co.jp/TC30/MC25585-SN5037.html`）を入れて「取得」
2. 左パネルで表示するスペック・画像・項目を選ぶ（POP 上の文字はクリックで直接編集可）
3. 「印刷 / PDF保存 (A4)」→ 印刷ダイアログで用紙 A4・余白なし・**背景のグラフィックを ON**

取得がブロックされた場合は、ブラウザで商品ページを開いて `Ctrl+U`（ページのソース）を全選択コピーし、
「ページのソースを貼り付け」欄に貼って「解析」してください。結果は同じです。

## 取得しているデータと情報源
| 項目 | 情報源 |
|---|---|
| CPU / GPU / メモリ / SSD / OS など全仕様 | 「製品仕様［基本構成］」テーブル（全項目を左パネルで確認可） |
| 短縮表記・価格・出荷目安・キャッチコピー | ページ内 `productJson` |
| 画像 | メインスライダーの原寸画像 + JSON-LD |
| ベンチマーク | 3DMark Time Spy / Fire Strike / Fire Strike Ultra |
| 分割払い・ラベル・管理コード・ラインアップ | 各 HTML 要素 |

仕様テーブルを優先し、無い項目は `productJson` で補完します。どちらも見つからない場合は画面に警告が出ます。

## テスト
```
python -m unittest discover -s tests -t .
```
`tests/fixtures/` は実ページ（MC25585-SN5037）から該当部分を抜粋したものです。

## CLI で JSON だけ取りたい場合
```
python scraper.py https://www.dospara.co.jp/TC30/MC25585-SN5037.html
```
