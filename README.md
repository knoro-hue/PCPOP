# PC POP メーカー（ドスパラ商品ページ → A4 POP）

ドスパラの BTO PC 商品ページの URL を入れると、スペック・画像・価格を取得して A4 縦の店頭 POP を作るローカルツールです。

## 必要なもの
- Python 3.9 以上（追加ライブラリ不要）

## 起動
```
python pcpop.py
```
Windows ならエクスプローラーで `start.bat` をダブルクリックでも OK。
ブラウザで http://127.0.0.1:8765/ が開きます。
ポート 8765 が使えない環境（WinError 10013 など）では 8080 → 8000 → 18765 → 28765 → 空きポートの順に自動で切り替わり、実際のURLが表示されます。`python pcpop.py --port 9000` のように指定も可能です。

## 使い方（個別POP）
1. 商品 URL（例: `https://www.dospara.co.jp/TC30/MC19364-SN5020.html`）を入れて「取得」
2. 店頭フォーマットの POP ができます（POP 上の文字はクリックで直接編集可）
   - 上部: GALLERIA ロゴ・「X-Series」・Model Name（型番）・管理番号（MC〜）
   - PC画像 ＋ 基本構成（GPU / CPU はロゴ風バッジ、メモリ / SSD / OS）
   - ゲーム性能（FHD / 4K の fps 表）… 商品ページに表があれば自動、無ければ空欄（POP上で入力）。3DMarkスコアにも切替可
   - 端子形状（USB Type-A / Type-C 系の 前面・背面の数を「入出力ポート」から集計）
   - 価格（税込）・三井住友分割払 月々・仕様（Wi-Fi / LAN / サイズ / 重量）・持込修理保証・分割手数料0円バナー
3. 左パネルで各項目の表示／非表示、PC画像を選ぶ
4. 「印刷 / PDF保存 (A4)」→ 印刷ダイアログで用紙 A4・**背景のグラフィックを ON**（画像の読み込みが終わってから印刷します）

フォント: 型番・シリーズ＝Bahnschrift Condensed 太字、価格＝Impact 太字（文字間隔広め）、その他＝メイリオ 太字
（どれも Windows 標準。無い PC では同梱の Anton で代用）。

### ノートPC（GALLERIA ノート / THIRDWAVE ノート）
スペックに液晶サイズ（インチ）がある商品はノート用のレイアウトになります。
- 重量の丸・画面サイズ（インチ / 非光沢液晶）・リフレッシュレート（Hz）・解像度・色域（製品仕様にある時だけ。例: sRGB 100%）
  （フォントは PowerPoint の原稿どおり: 数字＝Bahnschrift SemiBold、文字＝BIZ UDPゴシック）
- 右の表: `data/ul_specdate.json` に MC番号があれば「主な用途 / 目安」（THIRDWAVE ノート）、無ければゲーム性能（GALLERIA ノート）
- 濃いグレーの枠に CPU / GPU / メモリ / SSD / OS、下に「インターフェース仕様」（Wi-Fi・LAN・HDMI・USB の内訳・サイズ）
- THIRDWAVE はシリーズ名なし（ロゴを大きく表示）。右上は MC番号-SN番号

### カスタマイズ
商品ページのカスタマイズ選択肢（オフィスソフト・メモリ・CPUファン・CPUグリス・電源・SSD・無線LAN）を左パネルで選べます。
- 選んだ追加金額を足した合計を価格に表示（月々の分割額は 元の月々×合計/元の価格 の目安。POP上で修正可）
- メモリ・SSD は基本構成（ノートは濃いグレーの枠）に、無線LAN は Wi-Fi 欄にも反映
- それ以外（Office・CPUファン・CPUグリス・電源・無線LAN）は、下の分割手数料0円バナーの代わりに「カスタマイズ内容」の枠に表示
- 「標準構成に戻す」で元の構成・価格に戻ります

### 画像素材（pop_assets フォルダ）
`pop_assets` に決まったファイル名で画像を置くと、POP の該当箇所がその画像になります（無いものは文字のロゴで表示）。
例: `logo_galleria.png`（左上ロゴ）、`gpu_geforce.png`、`cpu_intel_core_ultra7.png`、`cpu_amd_ryzen.png`。
下部バナーは `banner_credit` / `banner_campaign` / `banner_warranty` / `banner_service` の4つを左パネルで選択（画像は **2232 × 408 px**＝186 × 34 mm）。
ファイル名の一覧は `pop_assets/README.txt`。

### ゲーム性能（data フォルダ）
`data` の `*.json`（`ul_fpsdate.json` と同じ形式）から、商品の MC 番号で fps を探して表に入れます。
画質（最高 / 中）・解像度（FHD / WQHD / 4K）・ゲーム（5本まで）は左パネルで選択。初期値は 最高・FHD/4K・
Apex Legends / Valorant / Monster Hunter Wilds / Cyberpunk 2077。JSON を差し替えると次の「取得」から反映されます。

### 「timed out」などで取得できない場合（社内ネットワーク）
1. まず直接接続を試し、失敗すると **Windows のプロキシ設定（ブラウザと同じ）経由** で自動的に再取得します。
   成功するとコンソールに「Windows のプロキシ設定経由で取得しました」と出ます。
2. それでも失敗する場合は、プロキシを明示して起動してください（アドレスは情報システム担当に確認）:
   ```
   set HTTPS_PROXY=http://プロキシのアドレス:ポート
   python pcpop.py
   ```
3. 最終手段として、下の「ページのソースを貼り付け」を使います。

取得がブロックされた場合は、ブラウザで商品ページを開いて `Ctrl+U`（ページのソース）を全選択コピーし、
「ページのソースを貼り付け」欄に貼って「解析」してください。結果は同じです。

## ランキングPOP（メイン画面・シリーズ別）
起動すると「ランキングPOP」タブが開きます（単品は「個別POP」タブ）。

1. 「ランキング取得（全シリーズ）」で `/TC30`（デスクトップ）と `/TC143`（ノート）を同時に開いて全シリーズを取得
   （取得するページは「取得するページ」で変更可・1行に1ページ）
2. ページ内の「〜ランキング」見出しごと（Xシリーズ / Fシリーズ / Eシリーズ / Nシリーズ…）にランキングを読み取り、
   「シリーズ」のボタン（常に全部表示）で選択 → 1〜3位が自動で選ばれます（チェックで入れ替え可・チェック順に1段目→3段目）
3. POP構成: 上部＝シリーズ名＋画像（WEBと同じく黒と白を重ねた2台並び。「トップ画像」で変更・アップロード可）／
   3段＝1〜3位の 訴求タグ・モデル名・CPU・グラフィックス・OS・出荷目安・価格・月々の分割価格（順位は王冠 金・銀・銅）
4. 使うのは指定ページに表示されている情報だけです。例外として、デスクトップ（/TC30）・ノート（/TC143）とも OS の代わりに
   **メモリ** を表示するため、各モデルの商品ページからメモリだけを読みます（取れなかったモデルは OS を表示）
5. 「印刷 / PDF保存 (A4)」（画像・背景の読み込み中は押せません。Ctrl+P で印刷しても、読み込み中は注意書きだけが出ます）

/gamepc のような単独ランキング（`ul.model-card-list.--ranking`）も1シリーズとして読めます。

ゲーミングノートの `https://www.dospara.co.jp/TC143`（「売れ筋人気ランキング」）にも対応しています。
カードの作りが違う（`li.get_ranking_data`、モデル名の欄がコメントアウトされている）ため、
表示前にモデル名の受け皿を足してからページの JavaScript に埋めさせて読み取ります（取れない時は商品画像の alt）。
シリーズ名はページ上部の「N Series for Gaming」から **N Series（ゲーミングノート）** とし、
スペック欄に **画面サイズ**（例: 15.6インチ）が加わります。

### ランキングの取得方法
ランキングはドスパラのページ上の JavaScript が後から表示するため、**PC の Edge（なければ Chrome）を画面に出さずに起動して
指定ページを開き、ランキング枠に商品が表示し終わるまで待ってから**読み取ります。ブラウザで見えている順位がそのまま取れます
（追加インストール不要。Windows のプロキシ設定もそのまま使われます）。
Edge/Chrome が別の場所にある場合は `set PCPOP_BROWSER=C:\path\to\msedge.exe` で指定できます。

それでも取れない場合は「ページを貼り付け」から。ドスパラのページを開いて F12 →「Console」のコード（またはブックマーク）で
**表示後のページ**をコピーして貼ってください（Ctrl+U の「ページのソース」には順位が入っていません）。

### デザイン（上部）
- 背景は GALLERIA 公式サイト（https://galleria.net/）のシリーズ紹介（S / X / F / E Series）の画像を、ツールがブラウザで開いて取得して使います
  （取れない時はシリーズごとの同系色グラデーション。左パネルのチェックで切り替え可）
- シリーズ名は白の英字「X Series」。フォントは Poppins（Italic）を同梱（`static/fonts`、SIL Open Font License）

### 画像の重ね方
ランキングの黒モデル・白モデルの画像をツール経由で読み込み、外側の余白だけを切り取ってから（画像そのものは加工しません）
「手前に黒、右奥に白（黒の幅の82%右へずらす）」で1枚に合成しています（WEBのカードと同じ見え方）。

### 速度について
- 取得したページは5分間キャッシュ（同じページの2回目は待ちません）

## 取得しているデータと情報源
| 項目 | 情報源 |
|---|---|
| CPU / GPU / メモリ / SSD / OS など全仕様 | 「製品仕様［基本構成］」テーブル（全項目を左パネルで確認可） |
| 短縮表記・価格・出荷目安・キャッチコピー | ページ内 `productJson` |
| 画像 | メインスライダーの原寸画像 + JSON-LD |
| ベンチマーク | 3DMark Time Spy / Fire Strike / Fire Strike Ultra |
| 分割払い・ラベル・管理コード・ラインアップ | 各 HTML 要素 |

仕様テーブルを優先し、無い項目は `productJson` で補完します。どちらも見つからない場合は画面に警告が出ます。
