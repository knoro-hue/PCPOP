# PC POP メーカー（ドスパラ商品ページ → A4 POP）

ドスパラの BTO PC 商品ページの URL を入れると、スペック・画像・価格を取得して A4 縦の店頭 POP を作るローカルツールです。

## 必要なもの
- Python 3.9 以上（追加ライブラリ不要）

## 起動
```
python pcpop.py
```
Windows ならエクスプローラーで `start.bat` をダブルクリックでも OK。
ブラウザで http://127.0.0.1:8765/ が開きます。
ポート 8765 が使えない環境（WinError 10013 など）では 8080 → 8000 → 18765 → 28765 → 空きポートの順に自動で切り替わり、実際のURLが表示されます。`python pcpop.py --port 9000` のように指定も可能です。

## 使い方
1. 商品 URL（例: `https://www.dospara.co.jp/TC30/MC25585-SN5037.html`）を入れて「取得」
2. 左パネルで表示するスペック・画像・項目を選ぶ（POP 上の文字はクリックで直接編集可）
3. 「印刷 / PDF保存 (A4)」→ 印刷ダイアログで用紙 A4・余白なし・**背景のグラフィックを ON**

### 「timed out」などで取得できない場合（社内ネットワーク）
1. まず直接接続を試し、失敗すると **Windows のプロキシ設定（ブラウザと同じ）経由** で自動的に再取得します。
   成功するとコンソールに「Windows のプロキシ設定経由で取得しました」と出ます。
2. それでも失敗する場合は、プロキシを明示して起動してください（アドレスは情報システム担当に確認）:
   ```
   set HTTPS_PROXY=http://プロキシのアドレス:ポート
   python pcpop.py
   ```
3. 最終手段として、下の「ページのソースを貼り付け」を使います。

取得がブロックされた場合は、ブラウザで商品ページを開いて `Ctrl+U`（ページのソース）を全選択コピーし、
「ページのソースを貼り付け」欄に貼って「解析」してください。結果は同じです。

## 人気ランキングPOP（メイン画面）
起動すると「人気ランキングPOP」タブが開きます（単品は「個別POP」タブ）。

1. ランキングのあるページURL（初期値 `https://www.dospara.co.jp/gamepc`）で「上位3件取得」
2. ランキング（`ul.model-card-list.--ranking` 内の全モデル）が一覧表示され、上位3件が自動で選択されます。
   チェックを付け替えて任意の3モデルを選び「選択したモデルでPOP作成」（チェックした順に 枠1→2→3）
3. 各枠の商品ページを取得してスペックを埋めます。順位バッジにはサイト上の実際の順位が入ります。
4. 各枠でテーマ（ゲーム赤／配信青／クリエイティブ緑）、説明文、画像を選択 → 「印刷 / PDF保存 (A4)」

### ランキングの取得方法
ランキングはページ上の JavaScript で表示されるため、**PC にインストール済みの Edge（なければ Chrome）を
画面に出さずに起動し、JavaScript 実行後のページを読み取ります**（追加インストール不要。Windows のプロキシ設定もそのまま使われます）。
Edge/Chrome が別の場所にある場合は `set PCPOP_BROWSER=C:\path\to\msedge.exe` で指定できます。

それでも取れない場合は「ランキングを貼り付け」から手動でも読み込めます（コンソール用コード／ブックマーク）。

### 速度について
- 直接接続できない環境では、一度失敗したら以降は直接接続を試さない（タイムアウト待ちをしない）
- 3商品は並列で取得、取得したページは5分間キャッシュ

商品ページが取得できない枠は、ランキング一覧の情報（CPU・GPU・価格・画像）で仮表示します。
メモリ・ストレージはその枠の「ソース貼り付け」に商品ページのソース（Ctrl+U）を貼ると補完されます。

## 取得しているデータと情報源
| 項目 | 情報源 |
|---|---|
| CPU / GPU / メモリ / SSD / OS など全仕様 | 「製品仕様［基本構成］」テーブル（全項目を左パネルで確認可） |
| 短縮表記・価格・出荷目安・キャッチコピー | ページ内 `productJson` |
| 画像 | メインスライダーの原寸画像 + JSON-LD |
| ベンチマーク | 3DMark Time Spy / Fire Strike / Fire Strike Ultra |
| 分割払い・ラベル・管理コード・ラインアップ | 各 HTML 要素 |

仕様テーブルを優先し、無い項目は `productJson` で補完します。どちらも見つからない場合は画面に警告が出ます。

## テスト
```
python -m unittest discover -s tests -t .
```
`tests/fixtures/` は実ページ（MC25585-SN5037）から該当部分を抜粋したものです。
